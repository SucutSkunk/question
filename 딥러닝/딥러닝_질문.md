## 3. Freeze와 Batch Normalization

- **Freeze**: `requires_grad = False`로 Optimizer가 파라미터를 업데이트하지 않게 하는 것입니다.
- **BN 구성**
  - γ, β: 학습 가능한 파라미터이므로 Freeze할 수 있습니다.
  - running mean/var: Gradient로 학습되지 않고, `train()` 모드에서 forward할 때마다 갱신됩니다.
- **핵심**: Freeze해도 `train()` 모드이면 BN 통계는 변할 수 있습니다.
- **해결**: Backbone을 `eval()`로 설정합니다. `model.train()` 호출 후에는 매번 다시 `eval()`을 설정해야 합니다.
- **구분**: Freeze는 파라미터 업데이트 여부를, `train()`/`eval()`은 BN·Dropout 등의 동작 방식을 제어합니다.

## 4. F1 Score와 오류 개념

- **Precision**: TP / (TP + FP), 양성 예측 중 진짜 양성의 비율 (오경보가 적을수록 높음)
- **Recall**: TP / (TP + FN), 실제 양성 중 잡아낸 비율 (놓침이 적을수록 높음)
- **F1**: Precision과 Recall의 조화평균, 둘 중 하나가 낮으면 크게 낮아짐
- **F의 의미**: F-measure(F-score)이며 정확한 약자는 불분명, 1은 Fβ에서 β=1을 뜻함
- **1종 오류**: 참인 H₀를 기각 (FP), 확률 α
- **2종 오류**: 거짓인 H₀를 기각하지 못함 (FN), 확률 β
- **연결**: FP ↔ Precision, FN ↔ Recall (Recall = 1−β = 검정력)
- **주의**: F1은 1종 오류와 무관하며, Precision ≠ 1−α(특이도가 1−α), F1의 β와 2종 오류의 β는 별개임
