## 예상한 컬럼과 실제 컬럼 비교

### 상황

| 구분 | 컬럼 |
|---|---|
| 예상 컬럼 | `text`, `author`, `tags`, `source_url` |
| 실제 컬럼 | `text`, `author`, `tags`, `Unnamed: 0` |

### 답안

1. **누락된 컬럼**: `source_url`
2. **예상하지 않은 컬럼**: `Unnamed: 0`
3. **올바른 구조인가?**: 아니요. 컬럼 개수(4개)만 같을 뿐 이름이 다릅니다. 검증은 개수가 아니라 **이름과 구성**으로 해야 합니다.
4. **확인할 저장 설정**: `to_csv()`의 `index` 옵션입니다.
   - 기본값(`index=True`)이면 인덱스가 이름 없는 첫 열로 저장됩니다.
   - `read_csv()`가 이 열을 읽으면서 `Unnamed: 0`이라는 이름을 붙입니다.

### 해결 방법

```python
# 저장할 때
df.to_csv("quotes_raw.csv", index=False, encoding="utf-8-sig")

# 이미 저장된 파일을 읽을 때
df = pd.read_csv(path, index_col=0)
# 또는
df = df.drop(columns="Unnamed: 0")
```

### 참고

- `source_url`이 없는 것은 수집 단계에서 값을 저장하지 않았다는 뜻입니다. 수집 코드도 함께 확인해야 합니다.
